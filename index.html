앱 내용과 인터랙션 구상

핵심 사용자 상황: 산책·회의 직후·출근길처럼 손으로 긴 문장을 정리하기 어려운 순간, 사용자는 음성으로 아이디어를 남기고 바로 구조를 확인합니다.

  1. 녹음 캡처: 한 버튼으로 녹음 시작/정지. 파형과 타이머가 상태를 명확히 보여줍니다.
  2. 텍스트 변환: 브라우저 Web Speech API가 있으면 실시간 인식, 없으면 직접 입력/샘플로 같은 흐름을 체험합니다.
  3. 핵심어 추출: 불용어를 제거하고 반복되는 명사·제품·행동 단어를 칩으로 보여줍니다.
  4. 마인드맵 구조화: 중심 주제에서 키워드가 뻗어나가며, 관련어끼리 가까운 위치에 놓입니다. 노드는 드래그 가능합니다.
  5. 인사이트/액션: 노드 클릭 시 “왜 중요한가”, “검증 질문”, “다음 할 일”을 생성해 아이디어를 실행 가능한 형태로 전환합니다.

주요 인터랙션: 녹음 토글, 샘플 불러오기, 텍스트 직접 수정, 보기 모드 전환, 키워드 칩 제거, 노드 드래그/선택, 요약 복사, 자동 저장.

향후 제품화: 모바일 위젯 녹음, 폴더별 지식 그래프, 회의록/Notion 연동, 음성 감정 태그, 팀 공유 마인드맵으로 확장할 수 있습니다.
